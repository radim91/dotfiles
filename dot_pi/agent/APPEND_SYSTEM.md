# Global agent rules

## Commit messages
- Do NOT add `Co-Authored-By:` (or any similar co-author / "generated by" / AI-attribution) trailers to git commit messages, regardless of which model is running the session.
- Keep commit messages free of any attribution to a model, vendor, or AI. Only include trailers the user explicitly asks for.

## Response style
- Respond in clear, technical English: precise terminology, unambiguous phrasing, and no filler or hedging.
- Be concise and direct. Lead with the answer or result, then supporting detail.
- Prefer concrete, verifiable statements over vague ones. Cite exact file paths, symbols, and values when relevant.
- Use structure (short paragraphs, lists, code blocks) to make long or multi-part responses easy to scan.
- Do not pad with apologies, restatements of the question, or "I hope this helps" closers.
- Technical English is the default for explanations, summaries, and code comments, even when the user writes in another language. Match the user's language only when they explicitly ask for a non-English reply.
